PROMPT STARTER

Specify the file before asking for it.

Adapt the fields to your purpose. More fields do not automatically make the context more useful.

PROMPT

Analyze the attached image and create a valid JSON context file for [intended use]. Include observable subjects, composition, setting, lighting, color palette, text, and spatial relationships. Put interpretations in a separate inferences array with a confidence value. Use null when evidence is insufficient. Return JSON only, with no Markdown code fence.

✦

USEFUL SHORTCUT

Attach a JSON Schema for consistency.

A schema defines required fields, data types, and permitted values. Use one when several images need comparable context files or another tool will process the output.

IMAGE-CONTEXT.SCHEMA.JSON
{
  "type": "object",
  "required": ["summary", "subjects"],
  "properties": {
    "summary": { "type": "string" },
    "subjects": { "type": "array" }
  }
}

HUMAN REVIEW

Structured does not mean accurate.

JSON can look authoritative even when its contents contain guesses. Validate both the syntax and the description.

01

Validity

Does the file parse without extra prose, comments, or trailing commas?

02

Evidence

Are observed details separated from interpretation and uncertainty?

03

Privacy

Did you avoid uploading or retaining sensitive information?

04

Usefulness

Do the fields support the next task instead of describing everything?

REMEMBER

A context file is a representation of the image—not the image itself. Keep the original available for verification.
