USEFUL SHORTCUT

Ask for assumptions before code.

Have Gemini list everything it cannot know from the screenshot—breakpoints, states, interactions, assets, content, and semantics. Correct that list first. A two-minute clarification pass prevents many rounds of polishing the wrong implementation.

RESOLVE FIRST

What the pixels cannot answer

Navigation Collapse, wrap, or scroll?

Cards Links, buttons, or static content?

Images Decorative or meaningful?

Mobile Stack order and spacing?

REVIEW BEFORE PUBLISHING

Pixel similarity is only one test.

The reconstructed page must also be lawful to use, meaningful without the reference image, accessible across input methods, and maintainable by someone other than the model.

01

Rights & identity

Replace protected logos, proprietary copy, photographs, and distinctive brand assets unless you have permission to use them.

02

Meaning & semantics

Confirm the heading order, landmarks, link text, labels, alt text, lists, tables, and forms communicate the page correctly.

03

Responsive behavior

Test narrow and wide screens, 200% zoom, text enlargement, keyboard focus, hover alternatives, overflow, and touch targets.

04

Code & security

Remove invented links, trackers, remote scripts, secrets, unsafe form handling, and dependencies you did not request or inspect.
