Step by step

Edit precisely in six moves.

The advantage is not simply generating a new picture. It is being able to target a small part of an existing image while keeping the rest of the composition intact.

01

Select

Choose an image

On a desktop computer, open a Google Doc or Slides presentation and click the image you want to change.

→Pics requires an eligible Google Workspace or Google AI plan.
▧Choose an image
02

Open

Click Edit image

Use the Edit image control to open Google Pics inside your document or presentation.

→If the older sidebar or bottom bar opens, your account may not have Pics access yet.
↗Click Edit image
03

Prompt

Describe the overall edit

Use the prompt box for changes that affect the entire image, such as lighting, color, mood, or style.

→State what should change—and what must stay unchanged.
✦Describe the edit
04

Target

Select an object or region

Click a detected element, or drag across a specific area. Add a short prompt describing only the change for that selection.

→Pics can queue up to five element, region, or text edits.
⌖Select an object or region
05

Refine

Edit text and elements

Select detected text to rewrite or restyle it. Review every targeted change before applying the group.

→Check spelling carefully—text inside generated images still needs human review.
TEdit text and elements
06

Replace

Apply and replace the image

Click Apply edits, then use Replace image to place the finished version back into Docs or Slides.

→Your Pics creations stay synced across supported Workspace apps.
✓Apply and replace
Replace image

Prompt pattern

Name the change. Protect the rest.

Object-level editing works best when the request distinguishes the target from the surrounding image.

Change [selected object or region] to [specific result]. Match the existing [lighting, perspective, texture, or style]. Preserve [people, background, text, colors, and other elements that must not change].

Target + change + continuity + constraints
✦

Useful shortcut

Queue related edits before applying.

Google Pics can hold up to five element, region, or text changes at once. Add a small set of compatible edits, review the list together, and then select Apply edits.

Review before replacing

Precision still requires judgment.

A targeted edit can unintentionally alter nearby objects, text, lighting, or meaning. Compare the result with the source before replacing it.

01

Meaning

Did the edit preserve the subject, message, and details you intended to keep?

02

Text

Is every word accurate, legible, and free of generated spelling errors?

03

Rights

Do you have permission to modify and reuse the source image?

04

Access

Does the final image have sufficient contrast and appropriate alternative text?

Availability: Google Pics requires an eligible plan and desktop access. If Edit image opens the older Docs or Slides editing interface, Pics may not yet be enabled for your account.
