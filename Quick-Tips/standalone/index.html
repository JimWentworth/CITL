USEFUL SHORTCUT

Put the rules inside the workbook.

Open Add work content in the Copilot prompt and choose Create workbook rules, or create a worksheet named .Rules. Record naming conventions, required formulas, validation logic, formatting, and prohibited changes so later Copilot edits follow the same specification.

.RULES

01 Never overwrite source data

02 Use structured table references

03 Flag errors without color alone

04 Explain new formulas

REVIEW BEFORE USE

A spreadsheet is an executable argument.

Its formulas, categories, defaults, and missing-data rules encode decisions. Review those choices with the same care you would apply to written analysis—especially when the workbook affects people, budgets, grades, or reporting.

01

Source & privacy

Use the Illinois-managed Copilot environment and include only data approved for that environment and purpose.

02

Structure

Check sheet names, table headers, data types, required fields, validation lists, keys, and blank-row behavior.

03

Logic

Inspect formulas, ranges, references, units, date handling, rounding, error handling, and edge cases.

04

Use & access

Check readable labels, contrast, keyboard use, chart titles and descriptions, color independence, instructions, and ownership.
