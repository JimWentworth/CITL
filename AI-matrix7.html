AI Capabilities, Bloom’s Taxonomy, and Cognitive Offloading

A University of Illinois–branded framework for helping faculty decide where AI can support learning and where student cognition should remain visible.

Why This Framework?

Faculty often ask whether students should be allowed to use AI on a particular assignment. A more useful question is: what cognitive work should remain with the learner?

This framework combines AI capability, Bloom’s Taxonomy, and cognitive offloading. It is designed to help instructors distinguish between tasks that build foundational understanding, tasks that can be productively automated, tasks that benefit from collaboration with AI, and tasks where student judgment should remain central.

How to Read This Framework

1. AI Capability

What kind of AI function is being used, such as natural language processing, computer vision, coding, or multimodal generation?

2. Bloom’s Taxonomy

What level of cognitive complexity is involved, from remembering and understanding to evaluating and creating?

3. Cognitive Offloading

How much of the thinking is being performed by the student, and how much is being shifted to the AI system?

Cognitive Offloading Zones

Learning Zone

Foundational knowledge and skills students should substantially build themselves.

Automation Zone

Routine or procedural work where AI may reduce effort without undermining learning.

Collaboration Zone

Tasks where AI can contribute ideas, drafts, specifications, or analysis while students remain active decision-makers.

Judgment Zone

Tasks involving evaluation, critique, ethical reasoning, or disciplinary judgment that should remain visibly student-led.

AI Capabilities Across Bloom’s Taxonomy

AI Capability Remember Learning Zone: recognize or define the capability Understand Learning Zone: explain access, purpose, and basic use Apply Automation Zone: use the capability to complete a task Analyze Collaboration Zone: determine task requirements and specifications Evaluate Judgment Zone: judge output quality and fitness for purpose Create Collaboration Zone: design advanced workflows, tools, or models
Natural Language Processing Define NLP and recognize examples such as summarization, translation, classification, and sentiment analysis. Explain how to access NLP tools and describe what kinds of text-based tasks they can support. Use NLP to summarize, classify, translate, rewrite, or extract information from text. Analyze the task requirements to determine whether the need is summarization, classification, extraction, translation, or generation. Evaluate NLP output for accuracy, bias, omissions, tone, reasoning quality, and fitness for purpose. Design or fine-tune an NLP workflow, chatbot, custom assistant, or model for a specific communication task.
Computer Vision Define computer vision and identify examples such as object detection, image classification, and visual recognition. Explain how to access tools that interpret, classify, or describe images. Use computer vision to identify objects, read visual information, compare images, or describe visual scenes. Analyze the visual task to determine whether it requires detection, classification, segmentation, comparison, or interpretation. Evaluate computer vision output for accuracy, misclassification, bias, missing context, and visual ambiguity. Design or train a computer vision workflow or model for a specific visual recognition or analysis task.
Data Processing & Analytics Define AI-supported data processing and recognize examples such as cleaning, sorting, summarizing, and pattern detection. Explain how AI tools can help organize, transform, visualize, and interpret datasets. Use AI to clean data, generate summaries, identify trends, create charts, or perform basic analysis. Analyze the data task to determine what variables, methods, comparisons, or transformations are needed. Evaluate AI-generated analysis for validity, assumptions, statistical weakness, misleading patterns, or unsupported conclusions. Design an AI-supported analytics workflow, dashboard, model, or decision-support process.
Coding & Software Development Define AI-assisted coding and recognize examples such as code explanation, debugging, documentation, and generation. Explain how to access coding assistants and describe what kinds of programming tasks they can support. Use AI to explain code, generate functions, debug errors, write documentation, or modify scripts. Analyze software requirements to determine needed logic, structure, dependencies, inputs, outputs, and constraints. Evaluate AI-generated code for correctness, security, efficiency, maintainability, and alignment with requirements. Design or build a software application, automation, agent, or coding workflow using AI as part of development.
Image & Video Generation Define generative image and video AI and recognize examples such as text-to-image, image editing, and video generation. Explain how to access image or video generation tools and describe how prompts influence output. Use AI to generate, revise, extend, or edit images and videos for a defined purpose. Analyze the visual communication need, including audience, style, medium, constraints, and design requirements. Evaluate generated media for accuracy, aesthetics, accessibility, ethical concerns, bias, and effectiveness. Create a visual campaign, storyboard, design system, or media production workflow using generative tools.
Multimodal Generation Define multimodal AI and recognize systems that combine text, image, audio, video, code, and data. Explain how multimodal tools process or generate across more than one type of media. Use AI to combine text, images, audio, video, or data into a coherent product or explanation. Analyze the communication or learning task to determine which modalities are needed and how they should interact. Evaluate a multimodal product for coherence, accessibility, accuracy, cognitive load, and audience fit. Design a multimodal learning experience, presentation, simulation, or interactive resource using AI tools.
Knowledge Graphs & Structured Reasoning Define knowledge graphs and recognize entities, concepts, relationships, and structured connections. Explain how knowledge graphs organize information and support retrieval, reasoning, and relationship mapping. Use a knowledge graph or mapping tool to trace relationships, organize concepts, or explore linked information. Analyze the domain to determine relevant entities, relationships, hierarchies, and missing connections. Evaluate a knowledge structure for accuracy, completeness, bias, usefulness, and conceptual coherence. Create an ontology, knowledge map, reasoning model, or structured knowledge system for a specific domain.

Reflection Questions for Faculty

  • Which parts of this assignment are foundational for student understanding?
  • Which parts are routine enough that AI support would not undermine learning?
  • Where could AI serve as a collaborator without replacing student thinking?
  • Where must students demonstrate their own judgment, critique, or disciplinary reasoning?
  • How will students document their use of AI, their decisions, and their revisions?

Key Takeaway

AI literacy is not simply about knowing how to use AI. It is about making intentional instructional decisions regarding which cognitive work should remain with learners, which work can be shared with AI, and which work can be safely automated.
